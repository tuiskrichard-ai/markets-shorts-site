Privacy Policy

Last updated: September 25, 2026

Markets Shorts Uploader ("the application") is a private tool used solely by its owner to upload original videos to the owner's own YouTube channel.

Use of YouTube API Services

The application uses YouTube API Services. By using the application, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy, which applies to data processed by Google and YouTube.

Information accessed and collected

The application requests only the youtube.upload OAuth scope for the owner's own Google account. It uses the YouTube Data API solely to upload videos together with their titles and descriptions (videos.insert). It does not read, collect, store or share any information about YouTube users, viewers, channels or videos, and it does not use cookies or tracking technologies.

How information is used and stored

The only information stored is the owner's OAuth refresh token, which is kept as an encrypted secret in the owner's private automation environment and is used exclusively to upload videos to the owner's channel. No YouTube API data is stored.

Sharing of information

No information is sold, shared with or disclosed to any third party. No information from YouTube API Services is shared with any other service.

Revoking access

Access granted to the application can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions.

Data deletion

Because the application does not store any YouTube API data, there is no such data to delete. The stored OAuth token is deleted immediately when access is revoked or when the owner removes it from the automation environment. Deletion requests can be sent to the contact address below and will be handled within 7 days.
